# DSP-project
Simple code used for DSP project focused on Caribbean percussion instruments.

## Motivation
To complete my first research publication as an aspiring physics major.

## Tech Stack
* Language:Python 3.14
* Core DSP Libraries: `librosa`, `scipy.signal` (Median Filtering), `soundfile`
* Data and Math Foundations: `numpy`, `pandas`

## Core Concepts
* Short-Time Fourier Transform Time-Frequency Conversion(STFT)
* Raw linear amplitute to Decibel conversion
* Noise Component Filtering and Reconstitution
